# Mutfak Cekmece Lastik Band Meclisi

Resmi ad: Cekmece Ici Elastik Isleri Yuksek Meclisi.
Kisa ad: BandMeclisi.
Statu: Gereksiz, calisir, ciddiye alinmaz, imza ciddiyeti tamdir.

Bu depo, mutfak cekmecesinin en arka kosesinde toplanmis lastik bantlarin yasama organidir. Bantlar secilmez. Cekmece acilinca hazir bulunurlar. Bu, tarihteki en durust secim sistemidir.

## Ne ise yarar

Hicbir seye. Yine de sunlari yapar:

- Bant envanteri tutar.
- Gerilim katsayisi hesaplar.
- Oturum acar, oy kullanir, kararname basar.
- Kopmak uzere olan bandi muhalefet ilan eder.
- Saglam bandi iktidar sandalyesine oturtur, sonra sandalyenin de cekmecede kayboldugunu tutanaga yazar.

Patates yoktur. Cekmece karistirilsa bile cikmaz.

## Kurulum

Python 3 yeter. Dis bagimlilik yoktur, cunku lastik bant da disaridan yardim istemez, icinden gerilir.

```bash
git clone https://github.com/Tentivory/mutfak-cekmece-lastik-band-meclisi.git
cd mutfak-cekmece-lastik-band-meclisi
python3 meclis.py
```

## Oturum komutlari

Program acilinca:

- `envanter` mevcut bantlari sayar.
- `oturum` gundem oylar, tutanak basar.
- `gerilim` ortalama esnekligi resmi rakama cevirir.
- `kararname` tek maddelik abartili genelge yazar.
- `cikis` cekmeceyi kapatir. Isik yanmaz. Bu buzdolabi degildir.

## Anayasa (kisa)

1. Her bant esittir, ta ki biri kopana kadar.
2. Cekmece acilmadan yasa yapilamaz.
3. Toplanti yeter sayisi: en az bir bant ve bir parmak.
4. Copilot bu mecliste danismandir, oy hakki yoktur. Copilot lastik bant degildir.
5. Gizli dosyaya bakmak serbesttir. Bakmamak da serbesttir. Ikisi de cekmece politikasidir.

## Copilot notu

`.github/copilot-instructions.md` dosyasi GitHub Copilot'a bu deponun dilini ogretir. Copilot'a sorarsan lastik bant meclisi agzindan cevap vermesi beklenir. Vermezse bant gerilmemistir.
